# Vedh Jayesh Naik — Personal Portfolio

An authentic, editorial personal portfolio for **Vedh Jayesh Naik** (Computer Science & Engineering student, ITM Kharghar). Designed with a publication-grade design system, clean web standards, and interactive features.

Live on Vercel: [https://vedh-portfolio.vercel.app/](https://vedh-portfolio.vercel.app/)

---

## Key Features

1. **Signature "Current Song on Repeat" Audio Player Widget**:
   - Located in the footer with a spinning vinyl record animation, dancing soundwave equalizer, track information, and Spotify links.
   - Built with an interactive **Web Audio API synthesizer** generating warm ambient chord progressions directly in the browser with zero external MP3 dependencies.

2. **Editorial Typography & Visual Hierarchy**:
   - Built with **Newsreader** (editorial serif) and **Plus Jakarta Sans** (contemporary sans-serif).
   - Warm parchment palette in Light Mode (`#fbfaf8`) and obsidian paper in Dark Mode (`#111113`).
   - Clean literary drop caps and generous white space.

3. **"My Projects (both serious and fun!)"**:
   - Filterable projects grid (Technical & Systems, Creative & Media).
   - Role badges, impact metrics, technical stacks, and direct repository/platform links.

4. **Chronological Resume & Credentials**:
   - High-signal track record highlighting education, leadership, and experience.
   - Direct PDF resume download support.

5. **Currently Learning**:
   - Current focus areas: cloud, security, and full-stack web.

6. **Zero Dependencies & Blazing Performance**:
   - 100% semantic HTML5, modern CSS3 variables, and clean vanilla JavaScript (ES6+).
   - Zero build step, instant deployment on Vercel.

## Local Development

Run the portfolio locally with any static web server:

```bash
# Python 3
python3 -m http.server 3000

# or Node.js
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Deployment to Vercel

```bash
# Deploy to production
vercel --prod
```
